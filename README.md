# 🍨 VM Belgium – Artisan Ice Cream E-Commerce Web App

## 🌐 Live Demo

👉 https://vmbelgium-u8fb.vercel.app

---

## 📌 Project Overview

**VM Belgium** is a responsive, modern e-commerce web application designed for an artisan ice cream brand.
The platform delivers a premium user experience through elegant UI design and interactive shopping features.

This project demonstrates strong frontend development skills, including **dynamic content rendering, state management using localStorage, and responsive UI design using Bootstrap**.

---

## 🚀 Features

* 🛍️ Dynamic product catalog rendered using JavaScript
* 🛒 Interactive shopping cart with add/remove functionality
* 💾 Persistent cart using browser localStorage
* 📱 Fully responsive design (mobile-first approach)
* 🎨 Smooth UI animations using AOS library
* 💰 Real-time pricing and subtotal calculation
* 🧾 Slide-in cart sidebar for seamless UX

---

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Framework:** Bootstrap 5
* **Libraries:**

  * AOS (Animation on Scroll)
  * Font Awesome
* **State Management:** LocalStorage
* **Deployment:** Vercel

---

## ⚙️ How It Works

1. Product data is maintained in a structured JavaScript array
2. UI components are dynamically generated and rendered
3. Users interact with products via add/remove cart actions
4. Cart state is stored in **localStorage** for persistence
5. Pricing is calculated dynamically and updated in real-time
